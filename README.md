# Solar Filament Segmentation — IEEE BigData Cup 2026

Pixel-precise instance segmentation of solar filaments in GONG H-alpha full-disk
observations, for the [Solar Filament Segmentation Challenge 2026](https://www.kaggle.com/competitions/filament-segmentation-2026).

The competition scores **Panoptic Quality (PQ)**, an instance-level metric. Everything
below follows from taking that seriously: PQ charges 0.5 for every false positive *and*
every false negative, so splitting one filament in two is punished twice over, and the
usual pixel-overlap intuitions do not transfer.

---

## The five measurements this design rests on

Rather than assume, each design decision was settled by a measurement. All of them are
regenerated by one command:

```bash
python tools/analysis.py
```

| # | Question | Answer | What it decided |
|---|---|---|---|
| 1 | What would a **human-quality method** score, under the real metric? | **PQ 0.674** (SQ 0.874, RQ 0.771) | The achievable ceiling, and the target. Measured by scoring each annotator's own masks as *the* prediction against **every** reading of that observation, self-match included — which is how the scorer treats our single prediction per image. |
| 2 | Does **averaging annotators** beat any single one? | union-of-two 0.646 vs single 0.637 IoU | Segmentation-quality ceiling ≈ 0.65, and a slightly *generous* boundary is closer to the average annotator → motivates `dilate_radius`. |
| 3 | Is **semantic segmentation + connected components** enough, or is a learned instance head needed? | **PQ 0.9967** on ground truth (13 FP in 1982 instances) | Annotated filaments essentially never touch. No Mask R-CNN, no instance head — the task reduces to producing one good binary mask. |
| 4 | What does working at **reduced resolution** cost? | round-trip IoU 0.868 @768, 0.888 @1024, 0.953 @1536 | Downsampling alone would consume more than the model could win back against a 0.65 ceiling → train and infer at **native 2048**, tiled. |
| 5 | Does **limb-darkening correction** help, and where? | separability 1.300 → **1.578** at r/R 0.85–0.95; unchanged at disk centre | The flat field earns its place exactly where a naive dark-region detector fails — at the limb. |

> **Do not use annotator-vs-annotator agreement as the ceiling.** Scoring annotator A
> against annotator B alone gives PQ 0.329 (SQ 0.631, RQ 0.521), which is *below* this
> model and would suggest the task is finished. That figure discards the self-match the
> scorer always includes, so it is not a ceiling and never was. The decisive check that
> annotator disagreement is not the binding constraint: out-of-fold PQ is **0.4163** on
> single-annotator observations, where an exact match is achievable by construction,
> against **0.4169** on multi-annotator ones.

### The operating point is derived, not tuned blindly

Under PQ, adding one predicted instance always raises the denominator by exactly 0.5 —
whether it converts a false negative into a true positive, or is simply a false positive.
It raises the numerator by its IoU only if it hits. So emitting a candidate with hit
probability `p` pays whenever

```
p · SQ > 0.5 · PQ        ⟺        p > 0.5 · PQ / SQ
```

At our measured levels (PQ 0.4167, SQ 0.6748) the bar is **p > 0.31**. The optimum is
strongly recall-biased: emit anything with better than a one-in-four chance of being real.
This is why the tuner searches low thresholds and small minimum areas.

## Pipeline

```
GONG H-alpha JPEG (2048×2048, 8-bit grayscale)
  │
  ├─ detect_disk        Otsu + largest component; radius from filled area (887/887 images, 0 failures)
  ├─ limb_profile       median intensity per radial shell (median, not mean: filaments are dark outliers
  │                     and would partly normalise themselves away)
  ├─ tile_features      3 planes → [limb-corrected contrast, raw intensity, normalised radius r/R]
  │
  ├─ FilamentNet        timm encoder + U-Net decoder to stride 1, squeeze-excite, deep supervision
  │                     trained on 512² tiles, 75% filament-centred
  │
  ├─ predict_full       overlapped tiles, raised-cosine blending, dihedral TTA
  │
  └─ extract_instances  hysteresis threshold → connected components → RLE
```

### Choices that differ from the obvious default

**Native resolution, tiled.** Measurement 4 rules out the usual "resize to 512 and run a
U-Net" approach. Filament barbs are a few pixels wide and are the first thing lost to
resampling.

**Augmentation is restricted to the 8 square symmetries.** No rotation or scale jitter:
these are exact pixel permutations, so unlike interpolating transforms they add no blur.
The Sun is radially symmetric, so a flipped or 90°-rotated tile stays physically
plausible — provided the radius plane is transformed with it, which it is. Photometric
augmentation is applied *only* to the two intensity planes, never to the radius plane,
which encodes fixed geometry.

**One training sample per annotator, not a fused consensus.** 707 observations carry 1154
independent readings. Treating each as its own example makes the network converge to
P(a randomly drawn annotator marks this pixel) — which is exactly the quantity the
operating-point rule above assumes it is thresholding. Binary cross-entropy is a proper
scoring rule, so it recovers that posterior; soft Dice is added at low weight purely to
condition the ~0.3% positive rate.

**Hysteresis thresholding.** A single threshold must serve two jobs at once — *which*
blobs to emit, and *how far* each extends — and PQ wants opposite settings for them. A
component is admitted only if it contains a confident core (`seed_threshold`) while its
extent comes from a looser level (`mask_threshold`). On a synthetic fixture, no single
threshold can both merge a faintly-bridged filament and reject a coreless noise blob;
hysteresis does both.

**Ensembling averages probability maps, not instances.** Merging instances across folds
would either duplicate a filament (false positives) or need an arbitrary voting rule.
Averaging first lets the tuned threshold judge each candidate exactly once.

## Layout

```
src/
  metrics.py         Panoptic Quality, SQ/RQ decomposition, one-to-many / many-to-one counts
  preprocess.py      solar-disk fitting, limb-darkening flat field, canonical-frame warps
  data.py            COCO parsing, site-stratified folds grouped by observation, image contexts
  dataset_torch.py   filament-biased tile sampling, dihedral + photometric augmentation
  model.py           FilamentNet: timm encoder + full-resolution U-Net decoder
  losses.py          masked BCE + soft Dice, deep supervision
  train.py           one fold; validated with real full-disk PQ, not a proxy
  infer.py           overlapped tiling, cosine blending, dihedral TTA
  postprocess.py     hysteresis → connected components; PQ-driven coordinate-ascent tuner
  evaluate_fold.py   score a fold and fit the decision parameters
  evaluate_oof.py    predict every observation with the model that held it out,
                     then fit one operating point over the whole training set
  predict_test.py    ensemble the folds, write and validate the submission CSV
tools/
  analysis.py        regenerates every measurement in the table above
  sync_src.py        publishes src/ as the Kaggle dataset the kernels attach
tests/
  test_pipeline.py       correctness of the pipeline, including its past bugs
  test_official_metric.py agreement with the host's published scorer
kernels/            thin Kaggle drivers (training, prediction, runtime probe)
```

## Reproducing

```bash
pip install -r requirements.txt
kaggle competitions download -c filament-segmentation-2026 -p data && unzip -d data data/*.zip
python src/build_disk_cache.py --root data/MAGFiLO_1.0_Kaggle_2026
python tools/analysis.py                      # regenerates the measurement table
python tests/test_pipeline.py                 # 28 checks, no pytest required
python tests/test_official_metric.py          # agreement with the host's scorer
python src/train.py --fold 0                  # trains one fold
python src/evaluate_fold.py --checkpoint artifacts/fold0_best.pt --fold 0
python src/evaluate_oof.py --checkpoints artifacts/fold*_best.pt   # pooled operating point
python src/predict_test.py --checkpoints artifacts/fold*_best.pt --config artifacts/oof_tuned.json
```

`notebooks/pipeline.ipynb` runs the whole thing end to end.

## A note on the public leaderboard

All 180 test observations also appear, with ground truth, in the public MAGFiLO 1.0
release. Under the Dice-based metric the leaderboard used until August this was plainly
visible — 28 teams were tied at exactly 1.00. The hosts switched the metric to Panoptic
Quality on 7 Aug 2026 and re-scored on 12 Aug; those perfect scores are now gone.

This solution does not use those annotations either way: it trains only on the provided
training split, and its predictions come from the model. Every decision is made against
local grouped cross-validation, scored with `src/metrics.py`.

That implementation is not assumed to match the host's. The organisers published a
[self-evaluation notebook](https://www.kaggle.com/code/azimahmadzadeh/self-evaluation-notebook)
defining the metric exactly, and `tests/test_official_metric.py` re-derives their rules
independently and asserts agreement — on multi-annotator observations, on empty
predictions, and on crowded overlapping cases where our greedy one-to-one matching could
in principle diverge from their all-pairs rule.

One consequence of those rules is worth stating, because it decides how predictions are
emitted. Ground truth is keyed by annotator *and* image, predictions by image alone, and
the scorer looks predictions up by image. An observation read by three annotators is
therefore scored three times against one and the same prediction set. Predicting once per
observation is not a simplification — it is the only thing the format can express.
