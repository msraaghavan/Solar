# The 4-page report

`report.tex` is **body text only** — paste it into the organisers' Overleaf
template (`kaggle_comp_report_fi_segm_2026.pdf`) beneath its title block. It
expects `amsmath`, `booktabs`, `graphicx`, `url` (or `hyperref`), and `tikz`.

Two things are deliberate:

**Every number is checked against an artefact, not transcribed from notes.**
`tools/check_report.py` re-reads the out-of-fold artefact and asserts that each
figure quoted in the text matches it. Run it after any edit; a report that
disagrees with the run it describes is worse than no report.

**The ablation section is marked `RESULTS-PENDING`.** Fill it from
`tools/compare_pods.py`, which reports each arm against its own paired baseline
and prints the noise floor first, so significance is visible rather than
asserted.
